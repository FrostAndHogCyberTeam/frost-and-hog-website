Security Checklist

Panduan Dasar Mengamankan Website Anda Sendiri

Banyak pemilik bisnis mengabaikan keamanan website mereka hingga terjadi hal yang tidak diinginkan. Berikut adalah 4 langkah dasar yang bisa Anda lakukan (atau minta tim IT Anda lakukan) untuk mengamankan website:

Langkah 1: Aktifkan HTTPS (SSL/TLS)

🛡️

Pastikan Ada Gembok di Browser

Jika website Anda masih menggunakan `http://` (tanpa 's'), data pengunjung (termasuk password) bisa dicuri. Gunakan sertifikat SSL (seperti Let's Encrypt yang gratis) dan alihkan semua lalu lintas ke `https://`.

Langkah 2: Perbarui Software Secara Rutin

⚙️

Jangan Gunakan Plugin/CMS Usang

Jika Anda menggunakan WordPress, Joomla, atau framework lainnya, pastikan semuanya menggunakan versi terbaru. Celah keamanan paling sering terjadi karena lupa *update* (pembaruan) pada sistem atau *plugin*.

Langkah 3: Gunakan Password yang Kuat

🔑

Jangan Gunakan Password yang Sama

Gunakan password yang panjang (minimal 12 karakter) kombinasi huruf, angka, dan simbol. Aktifkan Autentikasi Dua Faktor (2FA) pada akun admin website Anda.

Langkah 4: Lakukan Backup Berkala

💾

Selalu Siapkan Salinan Data

Lakukan backup (cadangan) file website dan database secara rutin (misal: seminggu sekali). Jika terjadi serangan *ransomware* atau *hacking*, Anda tidak perlu membayar tebusan karena punya cadangan data.
